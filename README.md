# Sentiment Dataset Analysis Project

## Project Overview

This project demonstrates the application of Python for data cleaning, exploratory data analysis (EDA), and data visualization using a sentiment dataset.

The project was completed as part of a Data Analytics Internship assessment and showcases fundamental data analysis skills using Pandas, Matplotlib, and Seaborn.

## Objectives

### Task 1: Data Cleaning and Preprocessing

* Load dataset using Pandas
* Check for missing values
* Remove duplicate records
* Standardize data formats
* Convert date columns to datetime format

### Task 2: Exploratory Data Analysis (EDA)

* Calculate descriptive statistics
* Analyze data distributions
* Identify relationships between variables
* Generate correlation matrix

### Task 3: Data Visualization

* Create bar charts
* Create line charts
* Create scatter plots
* Customize chart labels and titles
* Export visualizations as image files

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The dataset contains social media sentiment information including user engagement metrics such as likes, retweets, sentiment categories, platforms, and timestamps.

## Key Findings

* No missing values were found in the dataset.
* No duplicate records were identified.
* Data fields were successfully standardize
* Regular expression (Regez) was used to ensure that categorical text followed a consistent format
* Sentiment distribution revealed varying levels of positive, neutral, and negative sentiments.
* Engagement metrics such as likes and retweets exhibited observable relationships.
* Visualizations provided insights into sentiment patterns and user engagement trends.
